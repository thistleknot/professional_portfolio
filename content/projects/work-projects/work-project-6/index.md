## VPS Migrations & Client Infrastructure

**Industry/Domain:** Managed Hosting / Data Center

**My Role:** Linux Systems Engineer

**Timeline:** Oct 2018 – Dec 2018

## Key Contributions

**VPS Migration Operations**
- Executed live and cold migrations of client VPS instances between physical hosts
- Coordinated migrations during maintenance windows to minimize client-facing downtime
- Verified storage, network, and service continuity post-migration

**Infrastructure Management**
- Provisioned and maintained Linux-based virtual environments for hosted clients
- Supported network configuration and security requirements for enterprise accounts

## Technologies Used

- **Virtualization:** KVM, Linux containers
- **OS:** Linux (CentOS, Debian)
- **Networking:** VPC configuration, firewall management
- **Tools:** Bash scripting, system diagnostics
