## NER Pipeline Modernization

**Industry/Domain:** Aerospace & Defense

**My Role:** Data Scientist & AI Engineer

**Timeline:** Feb 2022 – Present

## Key Contributions

**Model Migration**
- Migrated from legacy rule-based NER to a SOTA transformer-based model, removing an EOL dependency
- Fine-tuned on proprietary aerospace corpus to preserve domain-specific entity classification
- Reduced model inference time through quantization and optimization

**Retraining Pipeline**
- Automated retraining pipeline with performance monitoring and drift detection
- Evaluation harness tracking precision, recall, and F1 across entity types

## Technologies Used

- **NLP & ML:** PyTorch, HuggingFace Transformers, spaCy
- **MLOps:** GitLab CI/CD, automated evaluation pipelines
- **Deployment:** CloudFoundry, Docker
