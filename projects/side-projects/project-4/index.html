Generative AI Studio: ComfyUI & Open-WebUI Orchestration

Self-hosted infrastructure combining ComfyUI’s node-based generative workflows with Open-WebUI’s unified LLM interface, showcasing hands-on expertise with state-of-the-art generative AI tooling.

Features

  • ComfyUI Advanced Workflows: Custom node chains for complex image generation, inpainting, style transfer, and multi-model composition
  • Open-WebUI Integration: Unified access to multiple LLM backends (local, cloud, mixed) with conversation persistence
  • Real-time Execution: Optimized pipeline execution with GPU resource management
  • Model Management: Automated model loading, caching, and resource allocation
  • Creative Experimentation: Rapid iteration on generative prompts, workflows, and model combinations

Technical Implementation

  • ComfyUI: Node-graph architecture for reproducible generative workflows
  • Open-WebUI: Web-based LLM interface with RAG capabilities and model switching
  • GPU Orchestration: Optimized VRAM allocation across concurrent generative tasks
  • Container Infrastructure: Docker-based deployment for reproducibility and scaling
  • Workflow Automation: Python scripting for batch generation and A/B testing

Impact

Demonstrates hands-on proficiency with leading open-source generative AI infrastructure. Shows ability to integrate and optimize complex multi-tool systems for creative and analytical applications. Direct experience with SOTA generative models in production settings.
